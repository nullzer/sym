# План разработки системы анализа видео

## Цель

Сделать локальную систему, которая принимает одно видео с производства
землеройных работ, анализирует наличие защитных касок у сотрудников и выводит
понятный результат: есть ли нарушения, где они произошли и какими кадрами
подтверждаются.

## MVP

1. **Загрузка видео**
   - CLI-команда для автоматического запуска.
   - Локальная web-форма для ручной загрузки одного файла.

2. **Обработка видео**
   - Проверка, что файл открывается.
   - Выборка кадров по `sample_fps`.
   - Фиксация таймкода каждого обработанного кадра.

3. **Детекция**
   - Основной backend: локальная ONNX-модель.
   - Ожидаемые классы: `person`, `helmet`, `no_helmet`.
   - Демонстрационный backend: цветовая эвристика OpenCV.

4. **Логика нарушения**
   - Признак нарушения на кадре:
     - найден `no_helmet`;
     - либо найден человек, но в верхней части его bounding box не найдена каска.
   - Соседние кадры объединяются в один эпизод.
   - Эпизод принимается только при достижении `min_hits`.

5. **Отчет**
   - `analysis.json` для интеграций.
   - `report.html` для просмотра результата.
   - Кадры-доказательства с отрисованными bounding boxes.

## Следующие итерации

- добавить страницу истории запусков;
- добавить ручную разметку спорных кадров;
- подключить обучение/дообучение на локальном датасете;
- добавить роли пользователей и журнал аудита;
- поддержать пакетную обработку видео;
- добавить экспорт PDF.

## Риски

- на дальних планах каска может занимать слишком мало пикселей;
- строительная техника и тени могут закрывать голову;
- модель, обученная на другом объекте, может ошибаться на новых касках,
  униформе или ракурсах;
- цветовые эвристики не заменяют обученную модель и нужны только для проверки
  контура приложения.
