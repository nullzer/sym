# Локальные модели

Положите сюда файлы detector backend:

- `helmet_detector.onnx` - ONNX-модель детекции;
- `labels.txt` - список классов, по одному на строку.

Рекомендуемые классы:

```text
person
helmet
no_helmet
```

Модель не хранится в репозитории, потому что обычно это крупный бинарный файл и
его нужно поставлять отдельно для офлайн-контура.
